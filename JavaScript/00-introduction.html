Tipos de escritas do JavaScript

  • No elemento HTML, usando innerHTML1, innerText ou textContent
  • Na saída HTML, usando document.write()
  • Na caixa de alerta (alert box), usando window.alert()
  • No console do navegador (browser), usando console.log
  • Impressão da página, usando window.print()
  1. innerHTML pode abrir portas para ataques do tipo Cross-Site Scripting (XSS), onde quem ataca injeta e executa código script malicioso.

innerHTML vs. innerText vs. textContent

  • innerHTML considera as tags HTML, retornam os conteúdos com marcação e pode inserir novos conteúdos HTML.
  • innerText e textContent ignoram as tags HTML, o que evita risco de ataques XSS, alé de considerar espaços e quebras de linhas.
  • innerText respeita o CSS, como style="white-space: pre". Descarta textos ocultos do CSS.
  • innerHTML e textContent consideram textos ocultos, que são códigos sem visibilidade display: none;, visibility: hidden;
