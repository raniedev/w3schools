Loops são execuções repetidas de um bloco de código baseado em uma quantidade de vezes.

Loops são fundamentais para tarefas involvendo:

    • Iteração sobre valores
      Iteração sobre estrutura de dados
      Executar uma ação múltiplas vezes
    • Loop Descrição
    for Itera sobre valores e expressões
    while Itera sobre uma determinada condição
    do...while Itera sobre uma determinada condição
    for...in Itera sobre as propriedades de um objeto
    for...of Itera sobre array como objetos
    forEach() Itera sobre cada elemento em um array
