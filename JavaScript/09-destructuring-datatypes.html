Tipos de Dados

Tipo de Dado Descrição
Number Representa valores numéricos
Bigint Representa valores numéricos grandes
String Representa texto
Boolean Representa um valor booleano, true ou false
Undefined Uma variável que não recebeu nenhum valor
Null Representação de valor nulo
Symbol Identificador único e primitivo
Object Uma coleção de chave-valor de dados
