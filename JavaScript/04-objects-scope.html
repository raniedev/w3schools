Objeto é uma variável que pode conter diversas outras variáveis (são chamados de atributos)

Objetos possuem coleções de pares chave-valor, onde cada chave tem um valor.

Objetos também podem armazenar métodos, como são chamados as funções no conceito de programação orientada à objetos.

Exemplo de Objeto

Propriedades Métodos
carro.nome = Nissan GTR carro.partida()
carro.modelo = R34 carro.dirigir()
carro.peso = 1750 Kg carro.freiar()
carro.cor = Cinza Fosco carro.parar()
